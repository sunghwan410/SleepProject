### 4. 기술적 내용

- 얼굴 검출: MediaPipe Face Mesh로 478개 3D 얼굴 랜드마크 실시간 검출
- 졸음 판단 로직:
    1. 눈 주변 랜드마크로 EAR(Eye Aspect Ratio) 계산
    2. EAR ≤ 임계값(EYE_AR_THRESH)이 연속 프레임(EYE_AR_CONSEC_FRAMES) 동안 지속되면 졸음으로 판단
- 시선/자세 추정:
    1. 코·턱·눈·입꼬리 2D 좌표와 3D 모델 매칭
    2. OpenCV solvePnP로 회전·이동 벡터 추정
    3. 오일러 각 Pitch, Yaw, Roll로 변환해 상하좌우 기울기 판정
- 알람 시스템:
    - 시각: 영상 위 "WAKE UP!" 오버레이, 배경 붉은 점멸(CSS 애니메이션)
    - 청각: JavaScript Audio + API 연동 경고음 재생
- 서버-클라이언트 통신:
    - 영상 전송: Flask Multipart Response 기반 MJPEG 스트리밍
    - 알람 신호: /alarm_status API를 1초 주기로 fetch polling, UI 알람 제어

### 5. 어려움과 해결

| 문제 | 극복 방법 |
| --- | --- |
| 가상환경 패키지 인식 오류 | 가상환경 인터프리터(.venv/Scripts/python.exe)를 명시해 ModuleNotFoundError 해결 |
| 실시간 알람 상태 연동 | 영상과 분리된 /alarm_status API 추가, 프론트엔드 주기 호출로 상태 동기화 |
| 시청각 알람 동시 구현 | fetch 콜백에서 CSS 클래스 변경과 오디오 재생을 함께 처리, 파일 부재 시 예외 처리로 시각 알람 유지 |

### 8. 결론

본 프로젝트를 통해 OpenCV와 MediaPipe를 활용한 실시간 컴퓨터 비전 애플리케이션의 설계부터 서비스 구현까지의 과정을 경험했다. 규칙 기반 모델을 Flask 백엔드와 JavaScript 프론트엔드에 통합해 성공적으로 동작하는 프로토타입을 완성했으며, 향후 딥러닝 모델을 도입해 판단 정확도를 고도화할 계획이다.
